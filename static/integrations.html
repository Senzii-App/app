What is an MCP server?

MCP (Model Context Protocol) is an open standard that lets AI assistants like Claude and ChatGPT connect directly to external tools and data. Instead of copying data between your scheduling software and your AI chat, the MCP server lets your assistant act on Senzii — create a staff member, check open shifts, assign someone to a shift, and more — without leaving the conversation.

Senzii's MCP server is the bridge. Your AI assistant talks to it using the MCP protocol, and it talks to Senzii's database using the same permissions and org scoping as the web dashboard. Everything stays secure and auditable.

Connect your AI assistant

Two ways to connect — remote (no installation) or local (run the binary yourself).

☁️

Remote (recommended)

Connect directly to https://senzii.com/mcp. OAuth 2.1 handles authentication — no API keys in your config. Works with Claude, ChatGPT, and any MCP client that supports remote servers.

  • ✓ No installation or binary to run
  • ✓ OAuth 2.1 with PKCE — secure login
  • ✓ Automatic org scoping from your account
  • ✓ Audit-logged actions
💻

Local (stdio)

Run the senzii-mcp binary on your machine with an API key from the Senzii dashboard. Best for local development or tools that only support stdio transport.

  • ✓ Runs entirely on your machine
  • ✓ API key from Settings → API Keys
  • ✓ Works with any stdio MCP client
  • ✓ Same 19 tools as remote mode

Claude (Anthropic)

Connect Senzii to Claude directly in claude.ai — no local installation needed.

  1. Go to Settings → Connectors → Add custom connector
  2. Enter the connector URL: https://senzii.com/mcp
  3. Claude discovers the OAuth endpoints automatically and prompts you to log in through Senzii
  4. Senzii tools appear in Claude's tool list

ChatGPT (OpenAI)

Connect Senzii to ChatGPT through Developer Mode (Plus, Pro, Business, Enterprise, and Education plans).

  1. Enable Developer Mode: Settings → Apps → Advanced settings → toggle Developer mode
  2. Create a connector: Settings → Apps → Create app
  3. Fill in:
    • Connector name: Senzii
    • Description: Manage staff scheduling, shifts, and staffing requests
    • Connector URL: https://senzii.com/mcp
  4. Click Create — ChatGPT connects and prompts you to authenticate
  5. Use it: new chat → + button → More → select Senzii

💻 Local (stdio) — any MCP client

Generate an API key in Settings → API Keys in the Senzii dashboard, then configure your MCP client:

mcp_servers:
  senzii:
    command: /opt/senzii/senzii-mcp
    env:
      SENZII_API_KEY: "your-api-key-here"

The server reads DATABASE_URL from /opt/senzii/.env automatically — no database credentials in the client config.

Security & architecture

Built with the same security model as the Senzii dashboard.

🔒 OAuth 2.1 with PKCE

Remote mode uses OAuth 2.1 with PKCE. Discovery at /.well-known/oauth-authorization-server. Dynamic client registration at /oauth/register.

🏢 Org-scoped

Every tool call is scoped to your organization. The AI never sees or controls the org ID — it's injected server-side into every database query.

📋 Audit logged

All write operations (create, update, delete, assign) are audit-logged with the authenticated user ID, timestamp, and changes.

🛡️ Role-based access

Admin, staff, and client roles determine tool visibility and data scoping. Staff can't see other orgs' data. Clients can only manage their own requests.

🔑 API key auth (local)

Local stdio mode uses API keys generated in the dashboard. Keys are shown once at creation and can be revoked anytime.

🔍 Read-only SQL

The run_sql tool only accepts SELECT statements. No mutations — INSERT, UPDATE, DELETE, DROP, ALTER, and CREATE are rejected.
